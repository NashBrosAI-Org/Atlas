# Atlas P3 — AI (additive) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Layer AI assistance onto Atlas — summaries first, then drafting, prioritization-assist, semantic search, and decks — without any feature ever *requiring* the Anthropic API (CLAUDE.md rule #6). Built behind an `AIClient` seam with a deterministic `FakeAI`, so it's TDD'd on the personal Mac against synthetic data.

**Architecture:** Mirror the ServiceNow/Graph seams. An `AIClient` Protocol (`app/ai.py`) with two implementations: `FakeAI` (deterministic, template-based — used in tests and as the demo default so the UI demonstrates with no key) and `AnthropicAI` (live, via the `anthropic` SDK with prompt caching). Feature logic (`app/summaries.py`, later `app/drafting.py`, …) is pure functions over `AIClient` + the existing `ServiceNowClient` data — assemble context from records, call `ai.complete`, return text. AI endpoints live under `/api/ai/*`. The deterministic core (the Now ordering, dossier, awareness, briefing) is untouched and remains the system of record; AI output is presented as *assistance*, never as the authority.

**Tech Stack:** FastAPI + pydantic v2, `FakeServiceNow`/`FakeAI`, pytest (`asyncio_mode=auto`), the `anthropic` Python SDK (live), React/Vite.

**Guardrails (read before building):**
- **Rule #6 — additive, not core.** No endpoint outside `/api/ai/*` may call the AI. The app must run fully with `ai_enabled=false`. The Now view stays deterministic; any AI "prioritization" is a *suggestion* surfaced separately, never a write to task priority.
- **Rule #1 — no corporate data on the personal Mac.** On the personal Mac the AI only ever sees synthetic `FakeServiceNow` data; that's fine to send to the real API. (The same code on the work Mac would summarize real records — that's the user's accepted retention/processing posture, R1/D2; keep the prompt scoped to what's already retained.)
- **Secrets.** `anthropic_api_key` lives in the macOS Keychain (service `atlas-sn`, like the SN password) and/or `.env` — never the repo (rule #2).
- **Live client uses the `claude-api` skill** (prompt caching, current model IDs). Default model: **Haiku 4.5** for cheap summarization; **Sonnet 4.6** where quality matters (drafting). Cache the system prompt + large context blocks.

**Gate:** Phases 1–2 are buildable now behind `FakeAI`. The live `AnthropicAI` (Phase 3) is also buildable here (synthetic data) but needs an API key; its tests mock the SDK.

```python
# backend/app/ai.py
"""AI access behind an interface, mirroring the ServiceNow/Graph seams. FakeAI is
deterministic — used in tests and as the demo default so AI features demonstrate
with no API key (rule #6: additive, never required). AnthropicAI (Phase 3) is the
live client. The deterministic core never calls this; only /api/ai/* does."""
from typing import Callable, Optional, Protocol, Union


class AIClient(Protocol):
    async def complete(self, system: str, prompt: str, *, max_tokens: int = 1024) -> str: ...


class FakeAI:
    """Deterministic stand-in. `canned` is either a fixed string or a
    (system, prompt) -> str callable so tests can assert on the prompt."""

    def __init__(self, canned: Union[str, Callable[[str, str], str]] = "[demo summary]") -> None:
        self._canned = canned
        self.calls: list[dict] = []

    async def complete(self, system: str, prompt: str, *, max_tokens: int = 1024) -> str:
        self.calls.append({"system": system, "prompt": prompt, "max_tokens": max_tokens})
        if callable(self._canned):
            return self._canned(system, prompt)
        return self._canned
```

```python
# backend/app/summaries.py
"""AI summaries: assemble context from existing records and ask the AIClient to
summarize. Pure logic over AIClient + ServiceNowClient. Additive (rule #6) — the
app never depends on these; only /api/ai/* calls them."""
from typing import Optional

from app import dossier
from app.ai import AIClient
from app.servicenow import ServiceNowClient

_SYSTEM = ("You are an assistant to a client-services manager. Summarize the client "
           "concisely for someone about to engage them. The app's task prioritization is "
           "deterministic and authoritative; your summary is assistance, not direction.")


async def summarize_client(sn: ServiceNowClient, ai: AIClient, scope: str,
                           client_id: str) -> Optional[str]:
    record = await sn.get(f"{scope}_client", client_id)
    if record is None:
        return None
    doss = await dossier.build_dossier(sn, client_id)
    lines = [f"Client: {doss['client'].get('name', '')} (status {doss['client'].get('status', '')})"]
    lines.append("Open tasks: " + "; ".join(t.get("title", "") for t in doss["open_tasks"]) or "Open tasks: none")
    lines.append("Engagements: " + "; ".join(e.get("name", "") for e in doss["engagements"]))
    lines.append("Recent notes: " + "; ".join(n.get("title", "") for n in doss["notes"]))
    prompt = "\n".join(lines)
    return await ai.complete(system=_SYSTEM, prompt=prompt, max_tokens=512)
```

```python
# backend/app/routers/ai.py
from fastapi import APIRouter, Depends, HTTPException

from app import summaries
from app.ai import AIClient
from app.config import get_settings
from app.main_deps import get_ai, get_sn
from app.servicenow import ServiceNowClient

router = APIRouter(prefix="/api/ai", tags=["ai"])


@router.get("/status")
def status() -> dict:
    s = get_settings()
    return {"enabled": s.ai_enabled, "model": s.anthropic_model}


@router.post("/summary/client/{client_id}")
async def summary_client(client_id: str, sn: ServiceNowClient = Depends(get_sn),
                         ai: AIClient = Depends(get_ai)) -> dict:
    out = await summaries.summarize_client(sn, ai, get_settings().sn_scope, client_id)
    if out is None:
        raise HTTPException(status_code=404, detail=f"client {client_id} not found")
    return {"summary": out}


@router.post("/summary/transcript/{transcript_id}")
async def summary_transcript(transcript_id: str, sn: ServiceNowClient = Depends(get_sn),
                             ai: AIClient = Depends(get_ai)) -> dict:
    out = await summaries.summarize_transcript(sn, ai, get_settings().sn_scope, transcript_id)
    if out is None:
        raise HTTPException(status_code=404, detail=f"transcript {transcript_id} not found")
    return {"summary": out}
```

## Phase 2+ — outline (each becomes its own plan)

- **Drafting** (`app/drafting.py`, Sonnet 4.6): draft a follow-up email or a note from a client/meeting context → `POST /api/ai/draft/...`; UI inserts the draft into the note/transcript composer for the human to edit. Never auto-sends.
- **Prioritization assist** (`app/prioritization.py`): the AI *suggests* an ordering/flag for open tasks, shown as a separate "AI suggestions" panel on Now. **Must not write `priority`** or reorder the deterministic Now list (rule #6) — it annotates, the human decides.
- **Semantic search** (own plan): embed notes/transcripts/emails; retrieve by meaning. Likely **pgvector** (see the `pg` skill) or a small local vector store; an embeddings `AIClient.embed` method extends the seam. RAG answers cite the source records.
- **Decks** (own plan): meeting/QBR decks as `.pptx` (via the `pptx` skill) and web decks on the **official ServiceNow brand kit**; content assembled from the dossier + summaries.
